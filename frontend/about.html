About

SPHEREx Blink

A web tool for looking for things that move or change in the SPHEREx all-sky survey. Built for the NASA Space Apps Challenge 2026, challenge “Planet X and SPHEREx”.

Data and software credits

SPHEREx data

NASA/JPL-Caltech, served by the NASA/IPAC Infrared Science Archive (IRSA).

Gaia DR3

European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC).

CatWISE2020

Based on data from NASA’s WISE and NEOWISE missions, served by IRSA.

Software

NumPy, SciPy, Astropy, Requests, FastAPI, Uvicorn.

Idea

Blinking the epochs of an infrared survey follows WiseView.

Use of AI

The code of this tool was written with the help of an AI coding assistant (Claude Code, Anthropic), working under the direction of the team. Files written this way carry the note “AI-assisted code (Claude Code)”.
